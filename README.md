# Soffit Commit

A private, local-first workspace for working with commits, documents, spreadsheets, and offline AI assistance.

## Download for Windows

Download the current Windows version from the [latest release](https://github.com/gmtechs/Soffit-Commit/releases/latest).

| Installer | Best for | Download |
| --- | --- | --- |
| Windows setup (`.exe`) | Most Windows users | [Download setup](https://github.com/gmtechs/Soffit-Commit/releases/latest/download/Soffit.Commit_0.1.0_x64-setup.exe) |
| Windows Installer (`.msi`) | Managed or enterprise PCs | [Download MSI](https://github.com/gmtechs/Soffit-Commit/releases/latest/download/Soffit.Commit_0.1.0_x64_en-US.msi) |

> The download links become available when the GitHub release is published. On Windows, use the `.exe` unless your organisation specifically asks for an `.msi` installer.
